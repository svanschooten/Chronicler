# Internationalisation

`chronicler/i18n/`

A nested message map per locale and a `t("path.in.map")` lookup, in the shape of Vue's
i18n rather than gettext — no `.po` files, no extraction step, no compilation.

## Using it

```python
from chronicler.i18n import t

ft.Text(t("settings.appearance.title"))
ft.Text(t("tasks.queued_transcribe", name="gm.wav", speaker="Alice"))
```

Parameters are `{named}` placeholders filled by keyword argument.

## Resolution and fallback

`Translator.t` walks a candidate chain and returns the first hit:

1. the active locale — `nl-be`
2. its base language — `nl`
3. `en`
4. the key itself

Returning the key rather than an empty string means a missing message shows up as
`settings.appearance.title` in the UI — visible and greppable — instead of a blank label
nobody notices.

A missing **parameter** leaves its placeholder in place rather than raising. A label
that reads `Queued {name}` is a bug you can see; a `KeyError` from a formatting call is
a crashed view.

## Locale selection

`build_runtime` calls `set_locale(settings.ui.locale)` at startup, so the locale comes
from configuration and applies before any view is built.

## Catalogue integrity is tested, not trusted

Four tests in `tests/chronicler/i18n/` keep translations honest:

* **No orphan keys.** Every key in a non-English catalogue must exist in English. This
  catches a key renamed in `en` but left behind in `nl`, which would otherwise sit there
  silently forever.
* **Every leaf is a string.** Catches a dict where a message was meant.
* **Placeholders match.** `{name}` in English must be `{name}` in Dutch — a translated
  string that renamed or dropped a placeholder produces a broken label at runtime.
* **Every call site resolves.** The package is parsed with `ast` and every literal
  `t("...")` key is checked against the English catalogue.

That last one is the important one: it means a typo'd key fails CI rather than shipping.

## Adding a locale

1. Add `chronicler/i18n/messages/<locale>.py` exporting `MESSAGES`.
2. Register it in `chronicler/i18n/messages/__init__.py`.

The integrity tests are parameterised over whatever is registered, so a new locale is
covered automatically. Partial translations are fine — anything missing falls back to
English.
